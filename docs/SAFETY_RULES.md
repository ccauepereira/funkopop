# Execution Safety Rules

AGY may:
- run Blender;
- run Python;
- create files inside the repository;
- render;
- export;
- inspect logs.

AGY may NOT without explicit approval:
- install system-wide packages;
- modify files outside the repo;
- delete project files;
- push to main;
- change git history;
- alter printer firmware;
- send commands directly to the printer;
- manually modify G-code;
- overwrite approved .blend files;
- overwrite measurements from physical tests.
